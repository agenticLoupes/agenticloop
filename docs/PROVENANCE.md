# Data and asset provenance

This ledger covers the two seed files and every file currently under `db/assets/`. Git history, file metadata, the generation script, and repository documentation were checked on September 19, 2026.

## License status

The public repository does not contain a `LICENSE`, `COPYING`, or `NOTICE` file, and GitHub reports no detected repository license. Repository-authored data and images therefore have no declared license. This document does not infer a license from public availability.
